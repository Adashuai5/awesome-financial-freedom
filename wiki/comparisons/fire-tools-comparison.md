# FIRE 工具横向对比

> 评估 `awesome-financial-freedom (Money OS)` 与主流 FIRE 计算器的差异，帮助你判断该用哪一个。
> 最后更新：2026-05-21

## 一句话总结

| 工具 | 适合 | 不适合 |
| --- | --- | --- |
| **awesome-financial-freedom (本项目)** | 中国大陆用户、A 股/公积金/个人养老金/综合所得税；希望本地隐私 + AI 集成 | 仅有美国资产、需要蒙特卡洛模拟的高级用户 |
| FIRECalc | 想看历史数据回测（1871-至今）成功率 | 中国市场参数、移动端、UX 友好 |
| Coast FIRE Calculator | 只想算 Coast FIRE 单一数字 | 完整规划、储蓄率优化、再平衡 |
| NetWorthify | 看储蓄率 → FIRE 年限的"魔法表格" | 多元资产、税务、CN 本地化 |
| cFIREsim | 蒙特卡洛 + 复杂提取策略（VPW、Guyton-Klinger） | 中文用户、简单初学者、移动端 |
| Personal Capital / Mint | 自动同步账户、被动追踪 | 主动规划、隐私（数据上传第三方） |

## 选型建议

**你应该用 awesome-financial-freedom，如果：**
- 你在中国大陆生活、收入和资产都是人民币
- 你想要一个能算公积金 + 个人养老金 + A 股 + QDII 配置的工具
- 你希望数据完全在本地、不愿意把财务信息交给第三方账户聚合服务
- 你想用 Claude / ChatGPT 做更深度分析，但需要一份结构化的输入
- 你是新手，需要"5 题诊断 → 阶段化工具 → 主计算器"的引导路径

**你应该用 FIRECalc，如果：**
- 你的资产主要在美国市场，希望用 1871-至今的历史数据回测 30 年成功率
- 你能接受简陋的 90s 风格 UI 和复杂的参数表单

**你应该用 cFIREsim，如果：**
- 你已经过了 FIRE 规划期，需要研究提取策略（VPW、Guyton-Klinger、Bond Tent）
- 你能编写 Python / 看懂蒙特卡洛分布图

**你应该用 NetWorthify，如果：**
- 你只想快速看一眼"储蓄率 50% → 17 年 FIRE"这张经典魔法表
- 你已经决定不深究细节，只需要一个心理锚点

## 本项目目前的短板（诚实清单）

1. **历史回测缺失**：蒙特卡洛已支持（对数正态收益），但没有 1970s 滞胀、1990s 日本通缩等具体历史路径回测
2. **σ 模型简化**：每年收益独立同分布，未刻画熊市聚集效应、序列风险（实际退休前 5 年风险被低估）
3. **税档仅 CN 综合所得**：未覆盖经营所得、利息股息所得、资本利得（A 股暂免）
4. **A 股数据非实时**：ETF 代码内置，但当前价格 / CAPE 估值需用户自行查
